# Cloverroad1.0 TEST
Native Java/Canvas Android8+ Country Road-style room-loop puzzle. Switch roads between cell centers to make one closed non-branching loop. Visit every outlined room in one continuous stretch, using exactly the A/B/C/D number of cells there. Two edge-neighbor cells left off the road cannot lie in different rooms. Tap halfway between centers to switch a road. Twelve unique 4x4 room/count boards, undo/reset, saved clover palette and off-road marks, GG007 menu/site/privacy.

Java ordered-cycle room-run and pairwise off-road oracle checks every cycle and 20000 random edge masks per board against production degree/floodfill, border crossings and quotas, confirming one solution each.
